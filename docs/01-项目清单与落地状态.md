## 五、与计划的三处偏离

| 偏离 | 原因 | 影响 |
| --- | --- | --- |
| MCP 未使用官方 SDK | 当前环境装不上 `mcp` 包 | 手写 stdio JSON-RPC，兼容 initialize 与 server/discover 两种入口；代价是没有 SDK 的类型校验 |
| report-lint 的 PDF 支持改为可选依赖 | 多数人只用 docx，`pymupdf` 体积不小 | 未装 `pymupdf` 时读 PDF 报 `E_DEPS_MISSING` 并给出安装命令 |
| 示例地址改用 RFC 5737 文档段 | 仓库自身的脱敏扫描会把公网示例判为泄露 | 扫描规则同步识别 192.0.2.0/24、198.51.100.0/24、203.0.113.0/24 |
